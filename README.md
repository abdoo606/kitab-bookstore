# 📚 KITAB — Premium Bookstore E-commerce Template

A premium, fully-featured bookstore e-commerce template built with React, TypeScript, and Tailwind CSS.

![KITAB](https://images.pexels.com/photos/28463480/pexels-photo-28463480.jpeg?auto=compress&cs=tinysrgb&fit=crop&h=400&w=1200)

---

## 🇺🇸 ENGLISH

### ✨ Features

#### 🎨 Design & UX
- 🌍 **Multi-language** (English, Arabic, French)
- 🌙 **Dark/Light Mode** with smooth transitions
- 💰 **Multi-currency** (USD, SAR, EUR)
- 📱 **Fully Responsive** (Mobile, Tablet, Desktop)
- ⚡ **Ultra Fast** with React + Vite
- 🎭 **Smooth Animations** with Framer Motion
- ↔️ **Full RTL Support** for Arabic

#### 🛍️ E-commerce
- 📖 **6 Book Categories** (Paperback, E-Book, Audiobook, Academic, Children, World Literature)
- 🛒 **Smart Cart** with persistent storage
- 🔍 **Search & Filter** by category, price, rating
- 💳 **Multiple Payment Methods** (Credit Card, Cash, Apple Pay, Bank Transfer)
- 📦 **Order Tracking** with visual progress bar
- 🎴 **Quick View** product modal
- 🏷️ **Badges** (New, Best Seller, Digital, Discount)

#### 👤 User System
- 🔐 **Authentication** (Login/Register)
- 📜 **Order History**
- 👤 **User Profile**

#### 🎛️ Admin Dashboard
- 📊 **Sales Statistics**
- 📦 **Orders Management** (change status with one click)
- 🛍️ **Products Management** (Add/Edit/Delete in all languages)
- 👥 **Users Management**
- 💰 **Multi-currency Pricing**

### 🚀 Quick Start

```bash
npm install
npm run dev
```
