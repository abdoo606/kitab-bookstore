# 📚 KITAB — Premium Bookstore E-commerce Template

**The ultimate bookstore template for selling paperback, digital, and audiobooks.**

Transform your bookstore idea into reality with KITAB — a beautifully crafted, production-ready e-commerce template designed specifically for book lovers and entrepreneurs.

## ✨ Why KITAB?

🎨 **Stunning Design** — Luxury aesthetic with pixel-perfect UI
🌍 **3 Languages** — English, Arabic (RTL), French — ready out of the box
🌙 **Dark & Light Mode** — Beautiful in any lighting
📱 **100% Responsive** — Perfect on mobile, tablet, and desktop
⚡ **Blazing Fast** — Built with React 19 + Vite for instant loading
🎭 **60fps Animations** — Smooth Framer Motion throughout

## 🛍️ E-commerce Features

- 📖 **6 Book Categories** — Paperback, E-Book, Audiobook, Academic, Children, World Literature
- 🛒 **Smart Cart** — Slide-out cart with persistent storage
- 🔍 **Search & Filter** — Find books instantly by category, price, or rating
- 💳 **4 Payment Methods** — Credit Card, Cash on Delivery, Apple Pay, Bank Transfer
- 📦 **Order Tracking** — Visual progress bar for every order
- 🎴 **Quick View Modal** — Preview books without leaving the page
- 🏷️ **Smart Badges** — New, Best Seller, Digital, Discount auto-tags
- 📄 **New Arrivals Page** — Dedicated page with newsletter signup
- 🔥 **Offers Page** — Countdown timer, top deals, discount highlights

## 🎛️ Admin Dashboard

- 📊 **Sales Statistics** — Total sales, orders, users, products at a glance
- 📦 **Order Management** — Change status with one click (Pending → Processing → Shipped → Delivered)
- 🛍️ **Full CRUD Products** — Add / Edit / Delete books in ALL 3 languages
- 👥 **User Management** — View all registered users

## 👤 User System

- 🔐 **Login & Register** — Complete authentication flow
- 📜 **Order History** — Track all past orders with status
- 💾 **Persistent Storage** — Cart and preferences saved automatically

## 🛠️ Tech Stack

- React 19 + TypeScript
- Tailwind CSS 4
- Zustand (State Management)
- Framer Motion (Animations)
- Lucide React (Icons)
- Vite (Build Tool)

## 📦 What You Get

✅ Complete source code (20+ components)
✅ 12 sample products with images
✅ Multi-language support (3 languages)
✅ Responsive design (all devices)
✅ Dark/Light mode
✅ Admin dashboard with full CRUD

✅ 10 screenshots
