Access model (Addendum #1 Q25) — no contractor access to DEWR's ArcGIS Online organisation

DEWR's GIS Analyst publishes each Web App, Dashboard, or StoryMap from DEWR's own ArcGIS Online organisation and shares a public URL. I embed that URL in a responsive, accessible block with a keyboard-reachable title and a plain link fallback. I never request an org-account login, API key, editing seat, or administrative role. Any change to a map is requested through the GIS Analyst and tracked on the change log; maps never break the page if a service is briefly unavailable.

ArcGIS embed slot — demonstration frame On the production site this frame loads one DEWR-published Web App, Dashboard, or StoryMap URL. Until DEWR supplies the real URL the frame stays a labelled placeholder. It is set to a fixed aspect ratio so nothing shifts while the map loads, and it carries a visible caption plus a “Open full screen in a new tab” link for keyboard and screen-reader users.

Project Explorer
