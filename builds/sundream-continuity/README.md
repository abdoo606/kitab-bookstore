# Sundream Continuity & Credit-Budget Director Workbench (Engineering Preview)

Custom interactive prototype built for **Sundream Studio (`sundream.studio`)** demonstrating:
1. **Scene-Graph Cast & Lighting Anchor Locking** across multi-shot AI films (*The Last Train*, *Sneaker Spec Ad*).
2. **Real Credit-Budget Auto-Router** optimizing across **Seedream 4.5 4K (`4 cr`)**, **Seedance 2.0 Mini (`28 cr / 8s`)**, and **MiniMax H3 2K (`104 cr / 8s`)**.
3. **Human-in-the-Loop Docked Director Assistant** (`Do it` / `Not now` proposals) + **Multi-Track Timeline & Pre-Export Cut Manifest Generator**.
