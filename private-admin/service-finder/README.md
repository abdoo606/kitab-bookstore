# باحث طلبات الخدمات — Service Request Finder v1

## الهدف
العثور على طلبات منشورة لشراء تطوير مواقع أو برمجيات، وليس جمع أعمال الوكالات السابقة أو وظائف الموظفين. هذه أداة فرز قابلة لإعادة التشغيل، وليست محرك بحث شامل أو نظام إرسال رسائل. المواقع الأولية تُضبط في sources.json؛ يجري اكتشاف روابط طلبات إضافية داخل نفس النطاق فقط في وضع live.

## التشغيل الذي تم فعلياً — 20 أكتوبر 2026
- 22 اختباراً ناجحاً، تشمل الفرز والتواريخ المتعارضة والمنتهية واستبعاد الوظائف وإعلانات الخدمات وتنظيف الروابط وأمان CSV وتطبيق robots وتحليل HTML. اختبارات الجلب تستخدم mocks؛ ليست إثباتاً لجلب حي.
- وضع live: الجهات الثلاث خارج قائمة الشبكة المسموحة في بيئة التنفيذ؛ سجلت الأداة المنع ولم ترسل لها HTTP. صفر صفحات جُلبت عبر requests. تفاصيل ذلك في results/live/run.json.
- أداة التصفح جلبت المصادر الرسمية، ثم حُفظت مقتطفات مختارة منها مع المصدر والتاريخ ونطاق الاقتباس في snapshots/ وsources.json. جرى تشغيل وضع snapshot فعلياً عليها: ثلاث سجلات، بلا أخطاء تحليل.
- النتائج ليست زحفاً شاملاً ولا قراءة آلية كاملة للمناقصات. لا توجد رسائل جديدة مرسلة في هذا التشغيل.

## الملفات
- scrape_clients.py: السكربت الرئيسي.
- test_scrape_clients.py: الاختبارات.
- sources.json: مصادر قابلة للتعديل، وهوية الجهة المعروفة يدوياً لا أول رابط خارجي.
- snapshots/: اقتباسات المصدر؛ ليست بيانات اصطناعية ولا صفحات كاملة.
- results/snapshot/opportunities.csv: النتائج المناسبة لإكسل، UTF-8 BOM وحماية من صيغ CSV.
- results/snapshot/opportunities.json: بيانات كاملة منظمة.
- results/snapshot/evidence/: النص الذي حللته الأداة لكل سجل.
- results/live/run.json: توثيق المنع الشبكي.
- results/tests.txt: نتيجة الاختبارات.
- requirements.txt: نطاقات إصدارات الاعتماديات؛ requirements-lock.txt: إصدارات البيئة التي اختُبرت.

## تشغيل نسخة قابلة لإعادة الإنتاج
يتطلب Python 3.9+.
```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell بدلاً من السطر السابق:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m unittest -v
python scrape_clients.py --sources sources.json --mode snapshot --as-of 2026-10-20 --out results/replay
```

## الجلب المباشر على جهاز يسمح بالاتصال بالمصادر
```bash
python scrape_clients.py --sources sources.json --mode live --max-pages 30 --depth 1 --out results/new-live
```
بدون --as-of يُستخدم تاريخ جهاز التشغيل. --allowed-hosts يقيّد الوصول لمضيفين محددين عند وجود سياسة شبكة. لا تُستخدم هذه الخاصية لتجاوز سياسة البيئة. المصدر الذي يعيد redirect يسجَّل للمراجعة، ولا يُتبع تلقائياً؛ يمكن إضافة الرابط النهائي بعد التحقق منه. لا يوجد تجاوز CAPTCHA أو تسجيل دخول أو اشتراكات أو حظر.

## إضافة مصادر جديدة
أضف في sources.json عنصرًا يحتوي على url، ويمكن إضافة organization وsource_kind. في وضع snapshot يلزم كذلك snapshot لمسار ملف نصي، وcaptured_on وcontent_scope لتوضيح تاريخ ومصدر ونطاق النص. مصادر الجهات الرسمية وصفحات RFP وطلبات المشاريع المباشرة أنسب من Behance أو Clutch. لا توجد API بحث أو كلمات مرور مخفية داخل البرنامج.

## ماذا تحسّن؟
- استخراج دليل طلب الخدمة، وتاريخ تقديم العروض منفصلاً عن موعد الأسئلة أو الإطلاق.
- حالات: منتهي، مغلق/ملغى، موعد اليوم يحتاج مراجعة الساعة، موعد قادم يحتاج تحقق، مواعيد متعارضة، موعد مجهول، وظيفة، إعلان بائع، ليست خدمة.
- ميزانية مقتبسة فقط عندما توجد عبارة ميزانية وعملة، دون اختلاق مبلغ أو عملة دفع.
- الإيميلات مرشّحات مع سياق، وليست هوية عميل مؤكدة. لا يختار أول رابط خارجي كموقع العميل.
- ملاحظات متطلبات الخبرة والمراجع والتأمينات، دون ادعاء أن غيابها بالنص يعني عدم وجودها.
- إزالة روابط التتبع والتكرار لنفس URL، مع بصمة ثابتة للمصدر وحفظ دليل الاستخراج.
- HTML وPDF نصي بحدود حجم وعدد صفحات؛ لا OCR أو متصفح JS في هذه النسخة.
- احترام robots.txt وتأخير الطلبات وحدود الصفحات والعمق؛ توقف عند 403/429 والأخطاء وتسجيلها.
- عناوين خاصة/محلية وروابط اعتماديات الدخول غير مقبولة، ولا متابعة تلقائية لإعادة التوجيه.

## الحدود والخطوة التالية
الفهم قائم على قواعد نصية، وليس تحققاً كاملاً من المعنى أو المؤهلات القانونية. التعرف على التواريخ يدعم أسماء الشهور الإنجليزية الكاملة وتنسيق YYYY-MM-DD؛ التواريخ العربية والاختصارات والمناطق الزمنية تحتاج مراجعة. قد توجد نتائج إيجابية أو سلبية خاطئة. عدم وجود تاريخ لا يعني طلباً مفتوحاً. الإعلان عن ميزانية لا يعني تمويلاً مضموناً. verified يبقى false دائماً حتى مراجعة بشرية خارج الأداة. إزالة التكرار حسب URL لا تمنع ظهور المشروع نفسه على رابطين مختلفين.

الخطوة العملية التالية: إضافة مصادر طلبات أصغر مناسبة لتنفيذ فردي وبناء مواقع كاملة، ثم مراجعة الجهة والمتطلبات والمواعيد والتواصل السابق قبل إرسال عرض. الأداة لا تعد بإيجاد 100 عميل، ولا تراسل أحداً، ولا تحوّل وجود RFP إلى صفقة.
