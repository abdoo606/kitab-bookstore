## ShieldScan MAX v3.0 — تطوير أقصى جديد (ضمن خط الأمان)
شو زاد عن v2 — كله من رابط واحد (بإذن الزبون):
- **زحف آمن لصفحات الموقع نفسه:** بيكتشف ويدقق حتى 8 صفحات داخلية (GET فقط، بيتخطى الملفات وروابط تسجيل الخروج/الحذف)، النتائج المتكررة بين الصفحات بتندمج («also on: …»)، والتقرير في جدول درجات لكل صفحة لحالها — يعني فحص «الموقع كله» مو بس الرئيسية.
- **فحوص تقوية ووردبريس:** نقطة REST للمستخدمين + readme + سكربت التثبيت + صفحة الدخول — رموز حالة فقط، ما بينقرأ أي محتوى مستخدمين.
- **سجل CAA بالـ DNS** صار بينفحص مع SPF/DMARC/DKIM/MX.
- **حزمة ترقيع قابلة للتنزيل مع كل تقرير:** `PATCH-PLAN.md` (مرتّبة بالأولوية + إعادة فحص للتحقق) + `nginx-security-headers.conf` + `apache-htaccess-security.txt` + `security.txt` + `dns-email-records.txt` — ملفات جاهزة تروح لمطور الزبون متل ما هي.
- اختبارات **10/10**. برهنة محدثة: هدف ضعيف **F — 0/100 (25 نتيجة، صفحتان مُدقّقتان)** وهدف محصّن **A+ — 98/100**. شغال بالمعاينة الحية على 8808 (v3).
- اللي ما بيعمله أبداً (ثابت من v1): حقن/استغلال/تخمين/سحب أسرار. الأدلة مُقنّعة مركزياً، وكل طلب مسجل بالتقرير.
