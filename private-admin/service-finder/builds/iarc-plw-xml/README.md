# IARC / Bulletin of the WHO — PLW Editorial Automation & JATS 1.3 XML Studio

Interactive technical demonstration built for **2026-10-RFP PLW Automation Software for IARC Publications**:
- Automated WHO/IARC house style rules verification (Latin italics, SI units, statistical CI/P formatting).
- Reference persistent identifier validation (`DOI` / `PMID`) with automatic editorial query flagging.
- IMRaD manuscript structuring and compliant **NCBI JATS 1.3 XML** generation.
