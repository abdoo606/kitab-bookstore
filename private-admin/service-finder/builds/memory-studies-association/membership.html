Annual conference — keep the specialist tool

Recommendation in one line: do not rebuild conference management inside the website. Keep submissions, peer review, registration, payments and programme-building in dedicated software (your current route such as Dryfta, or an evaluated alternative), and make the website the clean front door: key dates, fees, programme highlights and deep links. Single sign-on can be discussed in a later phase only if the conference platform supports it cleanly — it should not block the 1 July 2027 website launch. Full reasoning and costs are in the README sent with this sample.
